# Overview wireframe

Open `overview.html` directly in a browser. It uses the copied AutoKolab logo and needs no build step. Choose a situation above the frames to see busy, needs-you, calm, problem, and brand-new states. The phone frame follows the selected situation. All names and activity are sample data.

This is a proposed Overview structure, not an app implementation. The three main destinations are Captain, Overview, and Team, with Project as a small menu. This follows the navigation proposal in the coherence review and would need a new navigation decision before implementation. The states follow DEC-24: Overview is for looking, and requests are answered in Captain.

The wireframe omits count tiles, model and machine details, a separate review queue, and repeated work summaries. “See all work” and “Show the record” illustrate the path to detail; their dialogs are placeholders for the eventual linked pages.

No PNG previews are included: Chromium and Firefox could not start inside this sandbox. The HTML and copied SVG can be opened locally for visual review.
