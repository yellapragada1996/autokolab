# Current app: source audit

17 October 2026 · AK-159 · baseline `6686733`

This records what I could verify in this checkout. It supports the [proposal](proposal.md); it is not a usability test. I followed the router through every production screen, inspected the shared controls and data functions, and inventoried the helper's CLI, MCP tools, setup surfaces and runner capabilities. I did not read the other researcher's folder, ticket or branch. No environment files or private settings were read.

**Limits:** no live account, live database or GitHub approvals were exercised. A Playwright Chromium launch failed before a page opened: missing `libnspr4.so`. Desktop and phone appearance, focus behavior and touch usability remain unverified. Source inspection can establish that a control exists, not that a person understands it. The frequency estimates in the proposal are hypotheses.

## Documentation precedence and gaps

The [amendments](../../../autokolab-ux-handoff/00-AMENDMENTS.md) and DEC-24 in the supplied ticket override older handoff screens. I read principles, navigation, components, tokens and the relevant screen specs as design inputs. The [AK-145 review](../coherence-review.md) describes an older Overview and eight-item shell; those details are no longer today's implementation. Its core navigation proposal is an input to reconsider. The supplied ticket identifies the [Overview wireframe](../overview-wireframe/README.md) as approved; its README still calls itself a proposal. This research treats its visual order as the approved starting point, without treating its placeholder dialogs as working features. `docs/product-vision.md` is absent. The checkout's helper schema constant is 29; the supplied project brief's version 19 is older.

No hosted route was found for a standalone incident report, project-wide Pause everyone, machine update controls, complete local logs, quiet hours, installed-PWA push, a universal person/decision search or the Captain slide-over. These have prospective homes in the proposal; none is represented as already shipped. Parallel builds are open work in the supplied board, not a capability inferred from that ticket.
